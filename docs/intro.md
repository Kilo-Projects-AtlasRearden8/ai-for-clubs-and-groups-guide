# Welcome to AI for Clubs and Meetups

A plain-English, step-by-step beginner manual for running club and meetup
admin with free AI. Write agendas, newsletters, rosters, and event flyers
without spending a dime. Includes printable planners.

## Who this is for

You run (or help run) a club, hobby group, book club, meetup, or small
nonprofit. You don't need to be technical. You don't need to pay for AI. You
just need a phone or computer and about ten minutes per task.

## How to use each manual

1. Read the "You will need" box — usually just a free AI chat tool.
2. Work through the numbered steps in order.
3. Copy the example prompt, replace the fake details with your own
   (non-private) details, and paste it into the AI chat.
4. Read the AI's draft carefully. AI makes mistakes. You are the editor.
5. Print or save the final version. Use the planner sheet at the end of each
   manual if you want to work on paper first.

## The golden rule

**Never paste real member data into an AI tool.** No names, emails, phone
numbers, addresses, dues, or health info. Use made-up examples instead. See
docs/privacy.md for the full rule and why it matters.
