# Using GitHub for Clubs and Meetups

A beginner guide to using GitHub for club admin: storing documents, tracking
changes, and collaborating with other organizers. Free for public repositories.

## What is GitHub?

GitHub is a website where people store and share files, especially code and
documents. It keeps a history of every change, so you can always go back to an
older version. For clubs, it is a good place to keep:

- Meeting agendas and minutes
- Newsletter templates
- Event flyers
- Member sign-up forms (blank templates only — no real member data)
- Club policies and bylaws

## What you need

- A free GitHub account (github.com)
- About 15 minutes to set up your first repository
- No coding required

## Step-by-step: create a club repository

### Step 1: Sign up

Go to github.com and create a free account. Verify your email address.

### Step 2: Create a repository

Click the "+" icon and choose "New repository." Name it something like
`example-garden-club`. Choose "Public" (free) or "Private" (free for small
teams). Click "Create repository."

### Step 3: Upload your first file

Click "uploading an existing file" and drag in a document, for example your
club's meeting agenda template. Add a short description like "Initial agenda
template" and click "Commit changes."

### Step 4: Invite collaborators

Go to Settings > Collaborators and add other organizers by their GitHub
username. They can now edit files and suggest changes.

### Step 5: Track changes

Every time someone edits a file, GitHub saves a new version. You can see who
changed what and when. If a mistake is made, you can restore an earlier
version.

## Privacy reminder

**Do not upload real member data to GitHub.** Even private repositories can be
exposed if settings change. Upload blank templates only. Fill in real details
offline.
