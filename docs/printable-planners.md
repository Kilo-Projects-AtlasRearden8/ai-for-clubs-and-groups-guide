# Printable Planners

Print these pages (or copy them into a notebook) to plan your club's AI work
away from the screen. Nothing you write here ever goes into an AI tool.

## Agenda planner

Use before you ask AI to draft a meeting agenda.

```
============================================================
CLUB MEETING AGENDA PLANNER
============================================================

CLUB: _______________________________
DATE: _______________ TIME: __________
LOCATION: ___________________________
CHAIR: _____________________________
GOAL OF MEETING: ____________________
_____________________________________

AGENDA ITEMS (in order, with times):
1. ________________________________  ____ min
2. ________________________________  ____ min
3. ________________________________  ____ min
4. ________________________________  ____ min
5. ________________________________  ____ min

NOTES: ______________________________
_____________________________________
```

## Roster privacy sheet

Use on paper at sign-up events. Enter details yourself into a private
spreadsheet later. Never photograph this sheet and send it to an AI tool.

```
============================================================
NEW MEMBER SIGN-UP (PAPER ONLY)
============================================================

CLUB: _______________________________
DATE: ______________________________

Name: ______________________________
Email: _____________________________
Phone: _____________________________
Dues paid: [ ] Yes [ ] No

Keep this sheet in a locked drawer or private digital folder.
Never send it to an AI tool.
```

## Printing tips

- Print in black and white; these pages are designed to be ink-friendly.
- Fill in with pen or pencil, then follow the matching manual in `docs/`.
- Keep completed planners in a folder only club officers can access.
