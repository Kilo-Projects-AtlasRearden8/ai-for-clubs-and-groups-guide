# AI for Clubs and Meetups — Beginner Manual

A plain-English, step-by-step guide to using free AI models for club and meetup
work: agendas, newsletters, rosters, and event flyers. Includes printable
planners. No member data should ever be pasted into an AI tool.

**Published by Asdale Dynamics, LLC** — Indiana, formed October 2026.
Founder Dylan Asdale is a registered nurse turned AI author. His book *The
Massive AI Manual* and hub site dylanasdale.github.io explain AI "like a friend
would": plain English, step by step, never condescending.

This guide is part of the LLC's beginner-friendly AI education line: books,
guides, and practical tools anyone can use.

## What's inside

- `docs/` — full beginner manuals in Markdown (also usable as printable text)
- `site/` — static HTML website you can open in any browser or host for free
  (GitHub Pages, Netlify Drop, etc.)
- Printable planners for agendas, newsletters, rosters, and flyers

## Quick start

1. Pick a task: write an agenda, draft a newsletter, tidy a roster, or design a
   event flyer.
2. Open the matching page in `site/` (or read the matching file in `docs/`).
3. Follow the steps. Every step names a free AI model you can try.
4. Print the planner sheets and fill them in by hand or on screen.

## Golden rules

- **Never paste member data** (names, emails, phone numbers, addresses, dues
  payments, health info) into an AI tool. Use fake examples instead.
- **Free models only** — this guide sticks to no-cost options so any club can
  use it.
- **You stay in charge** — AI writes drafts; a human reviews and sends.
