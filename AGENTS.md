# AI for Clubs and Meetups

Plain-English beginner manuals for using free AI with clubs and meetups.

## What this repo contains

- `docs/` — Markdown manuals: agendas, newsletters, rosters, event flyers,
  free models, privacy rules, printable planners.
- `site/` — static HTML site (open in any browser, or host free on GitHub
  Pages / Netlify Drop).
- `LICENSE` — MIT License, Copyright (c) 2026 Asdale Dynamics, LLC.

## Privacy reminder (read first)

Never paste real member data — names, emails, phone numbers, addresses, or
dues — into an AI tool. Use made-up examples in every prompt.
